# B 대 C: 상위 5개 재정렬 개발 검색 시험

## 범위와 결론

동일 질문 10개에 대해 KURE·Solar 각각 B(BM25+벡터 RRF 상위 5개)와 C(B의 같은 5개를 GPT-6 Luna low로 재정렬)를 비교했다. 저장된 요청·응답·이벤트 기준 20/20건이 성공했고 각 요청은 정확히 5개 청크만 담았다. 이 결과는 검색 순위 시험이지 답변 생성, 의미적 정답성 검증, 사람 채점, 최종 평가가 아니다.

지정 앵커는 잠정 매핑이다. 미포함이 대안 근거의 부재를 뜻하지 않는다. D01~D08만 분모 8로 계산하며 D09·D10은 제외한다. 도큐먼트·색인은 파일럿 상태이고 운영 승인이나 공식 평가 요건을 입증하지 않는다.

Hit@k는 지정 앵커 하나 이상이 k위 안에 있는 비율, complete@k는 필수 앵커 모두가 k위 안에 있는 비율이다. complete-MRR@5는 모든 앵커가 모이는 가장 늦은 순위의 역수 평균이며 하나라도 없으면 0이다. 예를 들어 두 앵커가 1위와 3위면 Hit@1은 1, complete@1은 0, complete@3은 1, 역수는 1/3이다.

## 질문과 근거 없음 문항
