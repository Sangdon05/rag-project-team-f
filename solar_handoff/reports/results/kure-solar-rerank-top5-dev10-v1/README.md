# 상위 5개 재정렬 개발 시험

실행 준비만 완료. 실제 제공자 호출과 답변 생성·채점은 이 구현 단계에서 수행하지 않았다. 이전 시험 폴더는 변경하지 않는다.

- 고정된 B의 `final_top5` 5개만 요청에 넣고 숫자 1~5를 B 순서에 매핑한다. 구조화 출력은 5개 순위 필드이며 중복 없는 순열인지 별도로 검증한다. 5개를 모두 그대로 반환하므로 Hit@5와 complete@5는 순서 변경만으로 바뀌지 않는다. 이후 독립 평가는 Hit@1, Hit@3, MRR에 초점을 둔다.
- 입력 20건을 SHA-256 및 질문, 원본 청크와 대조한다. 제공자 요청은 동일 모델과 지시·스키마·설정을 쓴다. 입력 토큰 수와 실제 모델 지원 여부는 사전 검증하지 않았으며, 잘림을 비활성화하고 오류 시 즉시 중단한다. 고정 설정이나 스키마는 관련성·결정성을 보장하지 않는다.
- 요청 전 입력 파일과 시작 이벤트를 각각 flush 및 fsync한다. 응답 원문과 해시, HTTP 요청 ID, 응답 ID, 실제 모델, 사용량 및 시간을 기록한다. 오류·거절·미완료·형식 오류·순열 오류에서는 재시도나 대체 없이 중단하고 기존 파일을 보존한다. 민감정보가 발견된 응답은 안전상 원문을 저장하지 않고 중단한다. 네트워크 결과가 불확실하면 그 상태를 남긴다. 기존 실행이 있으면 재개하지 않는다.
- 비밀값은 루트 `.env`에서 메모리로만 읽는다. 전송 및 기록 전과 기존 실험 폴더 파일을 검사한다. 허용된 단일 정적 청크 경로 표현에 한해 DB 연결값 충돌을 예외 처리하며 API 키 등은 예외가 아니다. 데이터와 로그 전반의 검사는 제외하지 않는다.

## 오프라인 검증과 실행

저장소 루트에서 아래를 실행한다. 스크립트는 `python-dotenv`가 필요하다. 이 머신의 전역 Python에서는 확인했으나 프로젝트 가상환경에서의 설치 여부나 다른 팀원 환경은 보장하지 않는다. 설치·환경 변경은 수행하지 않았다. `TMPDIR`, `TEMP`, `TMP`는 승인된 스크래치 경로여야 한다.

```sh
export TEMP="$TMPDIR" TMP="$TMPDIR" PYTHONDONTWRITEBYTECODE=1
python -B results/kure-solar-rerank-top5-dev10-v1/test_runner.py
python -B results/kure-solar-rerank-top5-dev10-v1/runner.py preflight
```

`preflight`는 파일을 쓰거나 모델을 호출하지 않으며 비밀값을 출력하지 않는다. 실제 요청은 별도로 부모 에이전트가 실행한다. 호출 직전 사전 점검을 다시 하고, 비용과 결과는 실제 응답 전에는 알 수 없다.

```sh
python -B results/kure-solar-rerank-top5-dev10-v1/runner.py run
```
