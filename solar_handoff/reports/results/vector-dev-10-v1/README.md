- 데이터 출처: 기존 `pokedex_v3a_full_v1`, `v3a_full_151_20261125_v1`의 151문서·1,504청크, 모델마다 1,504벡터. 인덱스 설정 해시 `a74437dac60d16dbd34ad36fb54e6637646ea994a511eaf62f3928358426f06c`. 기존 적재 기록은 `../v3a-full-20261125/`를 참고한다.
- 입력은 세 모델에 동일한 원문 질문이며 클라이언트 접두사·분할은 없다. 로컬 요청은 `truncate=false`, `num_ctx=8192`; 사전 기록의 적재 설정과 일치한다. 서버 내부 토큰화·숨은 전처리의 완전한 동등성은 확인되지 않았다. OpenAI 모델은 고정 불변 리비전이 아닌 제공자 별칭이다.
- 벡터 전용 exact cosine, k=5, 의미 필터 없음(대상 index_version 제한만 적용), 거리 오름차순 및 `chunk_id` 동점 정렬. 인덱스 및 bitmap 스캔 비활성화로 전체 스캔한다. BM25·재정렬·생성 없음.

## 산출물과 검증

- `config.json`: 코드에 고정한 실험 설정의 문서화 사본. 실행기는 이 파일을 설정 입력으로 읽지 않으며 `run.py`의 상수와 사전 검증을 사용한다. 이 사본의 바이트 SHA-256은 `f997805ec3f6b8d5e7f6ea03b0638ff528bfb72f539ab1c5dc11e68724357749`.
- `raw.json`: 30개의 모델·qid 행, 각 행의 상태·5개 순위·거리·문서 ID·상대 경로·제목·제목/본문 줄 목록·문서 해시·실제 검색 시간. 배치별 모델 사용량·실측 배치 시간을 별도 기록한다. 질의별 임베딩 시간은 배치 요청이라 측정하지 않아 `null`이다. 바이트 SHA-256 `9a76848d3e757ac2ba1565ed54ebe205303bbe9fdcd11389237fb911a5e9f2b8`.
- `execution-started.json`: 실요청 전 배타적으로 작성한 실행 표식. 기존 표식이 있으면 재실행하지 않는다. 성공이든 불확실한 실패든 자동 재시도하지 않는다.
- `run.py`, `test_run.py`, `checks.json`: 실행 코드, 오프라인 fake API/DB 검사와 별도 읽기 전용 EXPLAIN 기록. 실행에 사용한 과거 DB target/OID/cluster 사전 기록은 로컬 scratch의 `v3a-full-20261125/preflight.json`이며 기존 공유 결과에 기록된 SHA-256과 비교한다. scratch는 공유·영구 보존이 아니므로 다른 환경에서 그대로 재실행 가능한 독립 배포물은 아니다. 실행 코드의 사용자 승인 이외 재실행은 금지한다.
- 선행 검증: SQL `REPEATABLE READ READ ONLY`와 별도 NOLOGIN 실행 역할에서 기존 기록과 DB/cluster/role/extension/owner/ACL을 비교했다. 세 모델 config·로컬 digest, 각각 1,504개 고유 ID, 문서 본문/메타데이터 해시와 벡터-청크 대응·차원·벡터 집합 해시를 확인한 후 요청했다. 역할 전환은 관리자 로그인에 의한 실행 범위 제한이지 관리자로부터의 보안 샌드박스는 아니다.
- 오프라인 검증: `pokedex_v3a/.venv/Scripts/python.exe -m unittest discover -s results/vector-dev-10-v1 -p 'test_*.py' -v` → **7 tests OK**. 실결과 재확인: 30개 고유 모델×qid, 상태 `ok` 30개, 순위 길이 5인 행 30개, 각 결과 출처 메타데이터 존재.

## 사용량 및 제한

| 모델 | 실제 배치 수 | 질문 수 | 응답 사용량 | 임베딩 배치 실측 시간 |

| KURE | 1 | 10 | prompt_eval_count 304 | 2286.24 ms |
| OpenAI | 1 | 10 | prompt_tokens 516, total_tokens 516 | 1411.62 ms |

시간은 단일 배치 전체 시간이지 질문별 시간이나 통제된 성능 벤치마크가 아니다. 실제 청구 비용은 **미상**이다. 토크나이저별 사용량은 직접 비교할 수 없다. DB와 기존 인덱스는 읽기만 했고 raw vector 및 자격 증명은 의도적으로 저장하지 않았다. 다만 짧은 DB 비밀번호의 문자열이 지정된 DB 이름 및 기존 모듈 이름 일부와 우연히 같아 코드에 그 문자열이 포함된다. 이는 자격 증명을 복사한 것은 아니지만 공유 전 약한 비밀번호와 식별자 충돌을 검토해야 한다.

이 자료는 **무채점 검색 원본**이다. 정답·허용 근거·채점표를 읽거나 검색기에 넣지 않았다. 검색 결과만으로 답변 거절의 적절성이나 생성 답변 품질을 판단할 수 없다. 품질 채점과 채택 판정은 독립 평가자가 수행한다. 정식 held-out 평가는 실행하지 않았다.
