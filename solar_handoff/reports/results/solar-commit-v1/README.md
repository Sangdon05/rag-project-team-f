# Solar 벡터 단회 적재 실행 기록

## 범위 및 출처

사용자가 승인한 기존 Solar 보존 벡터를 실행기로 DB에 단회 적재한 결과다. 아래 수치는 부모 에이전트가 전달한 실행 및 독립 읽기 검증 결과이며, 이 기록 작성자는 DB·API·저널 벡터를 재확인하지 않았다. 적재 대상 식별 정보와 원본 설정은 기록하지 않는다. 인덱스 버전은 전달되지 않아 미상이다.

## 적재 및 검증 결과

- `solar_commit.run` 상태: `verified`; 벡터 1,504개, 문서 151개, 배치 376개.
- PostgreSQL 단일 트랜잭션에서 한 번 commit했고, 실제 실행기는 별도 신규 연결로 commit 후 readback했다.
- 별도의 읽기 전용 트랜잭션 검증: 1,504행, 고유 ID 1,504개, 벡터 차원 최솟값·최댓값 1,024. 전체 1,504행이 기준 청크 ID 및 content hash에 올바르게 연결됐고 Solar 벡터 digest가 일치했다.
- gemma, kure, openai 기준선은 각각 1,504행이며 벡터 digest가 보존됐다.
- Solar 벡터 SHA-256: `7d138730778a7fa35df5c9a91aa13427f5f36dfdc52d197a611188c51ab82873`
- Solar 설정 SHA-256: `80c2b8677bc57579524a746a83645926b71a96b90d4c5cd8f0569ab82de926fb`
- 실행 receipt SHA-256: `8369eba3a6266a6326ef450f761636661647a0f83b6c4f646d7e65b380465e99`

위 해시는 전달받은 값이며 이 문서 작성 시 원본 바이트를 재해시하지 않았다. 해시 일치는 바이트 동일성 검사용이지 출처의 진위 인증이 아니다.

## 한계

- 운영자의 이번 적재 호출은 기존 저널을 사용했고 직접 제공자 API를 호출하지 않았다. 별도 추가 제공자 호출 여부 감사와 원본 벡터의 출처 진위 인증은 미검증이다.
- 실제 토큰화 및 서버 잘림 여부는 미검증이다. 제공자 보고 총 `prompt_tokens`는 332,848이며 비용은 미상이다.
- 이 기록은 검색 smoke test, 품질 평가, 운영 활성화, 증분 sync 또는 문서별 사실 검증을 확인한 것이 아니다. 재적재·재임베딩이나 추가 평가를 수행하지 않았다.
- 로컬 `runs/manifest.jsonl`은 Git ignore 대상이므로 팀 공유 기록을 대체하지 않는다.
