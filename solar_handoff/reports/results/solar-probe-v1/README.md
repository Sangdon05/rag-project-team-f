# Solar Embedding 2: 소량 연결 확인

기존 승인 청크 `pokemon:1#profile`와 `results/v3a-full-20261125/full.json`의 `input_policy.questions.type` 원문을 각각 passage와 query 모델에 1회 전송하는 탐색용 확인이다. 실제 원문이 Upstage로 전송되며 소액 API 요금이 발생할 수 있다. 가격 안내: https://www.upstage.ai/pricing (기준으로 전달받은 요율: 100만 토큰당 USD 0.02, 부가세 별도). 실제 청구액은 확인하지 못했다. API 문서: https://developers.upstage.ai/

두 입력 및 파일의 SHA-256을 고정하고 청크 파일을 Git HEAD와 비교한다. 질문 파일은 기존 실행 산출물이며 Git 추적 파일이라는 뜻은 아니다. API 키 및 모델 역할은 저장소 루트 `.env`에서 해당 세 항목만 선택하여 읽는다. 키, 입력 원문, 응답 원문, 벡터는 저장하지 않는다. 각 호출 직전/직후 `events.jsonl`에 fsync 기록을 남긴다. 기존 파일이 있으면 실행을 거부하며 실패 시 재시도하지 않는다. 기록된 벡터 해시는 원소를 IEEE 754 float32 빅엔디언으로 순서대로 직렬화한 바이트의 SHA-256이다.

모델 이름은 `UPSTAGE_EMBEDDING_MODEL`과 `UPSTAGE_QUERY_MODEL`에서 각각 읽는다. 이 탐색 스크립트는 비어 있거나 동일한 값, 키가 포함된 값 및 역할 접미사 `-passage` / `-query`가 맞지 않는 값을 거부하며 응답 모델명도 요청과 대조한다. 접미사 검사는 제공자 모델의 실제 역할에 대한 독립적인 증명은 아니다.

**실행 코드 출처 제한:** 기존 `events.jsonl` 기록 당시에는 `probe.py` 코드 해시를 기록하지 않았다. 이후 HTTP 오류 자원 정리와 모델 설정 처리 코드를 수정했으므로 현재 `probe.py`는 당시 실행한 코드와 동일하지 않다. 기존 이벤트만으로 당시 실행 코드의 정확한 해시나 내용을 검증할 수 없다. 이벤트는 변경하지 않았고 실 API를 재호출하지 않았다.

**제약:** 이 실험은 임베딩 차원과 API 응답만 확인한다. 검색 품질 비교, DB 삽입, 순위 측정이나 전체 코퍼스 처리는 하지 않는다. 토크나이저 일치, 토큰 제한 준수, 서버가 원문 전체를 사용했는지는 확인되지 않았다. 응답에 잘림 표시가 없더라도 잘림이 없다는 증거가 아니다. 토큰 수는 제공자가 실제 반환한 usage만 기록한다. 모델 이름은 불변 리비전으로 보장되지 않는다.

오프라인 검증: `python -W error::ResourceWarning -m unittest discover -s results/solar-probe-v1 -p test_probe.py -v` (합성 모델과 모의 응답만 사용, 실제 네트워크 없음). `probe.py`는 유료 외부 전송을 실행하므로 기록이 남은 상태에서 반복 실행하지 않는다. 시작 이벤트만 있거나 실패 결과가 있으면 결과가 불확실할 수 있으므로 자동 재시도하지 않는다.
