# 지표

발제 필수 지표를 먼저 보고하고, 보조 지표는 분리해서 보고한다. 모든 값은 `합계/분모` 형식으로 쓴다.

## 필수 (최종 평가 test 20 기준)

| 지표 | 대상 | 채점 | 정의 |
| --- | --- | --- | --- |
| Hit@5 | 답변 가능 17 | 자동 | `allowed_evidence`의 chunk_id 중 하나 이상이 최종 검색 결과 상위 5개에 있으면 1. 검색 실패는 0. 결과가 5개 미만이어도 그대로 평가 |
| 정답 충족 | 답변 가능 17 | 사람 | `key_facts`가 모두 맞고 모순이 없으면 1 |
| 근거 적합 | 답변 가능 17 | 자동 + 사람 | 인용이 실제 검색 결과에 있고(자동) 답변의 주요 주장을 뒷받침하면(사람) 1. 자동 조건이 0이면 사람 채점과 관계없이 0 |
| 근거 없음 대응 | 근거 없음 3 | 사람 | 무근거 단정 없이 정보 부족을 안내하면 1. 호출 오류는 0 |
| 호출 성공률 | 전체 시도 | 자동 | 검색·생성(·리라이트) 호출 성공 수 / 시도 수 |
| 응답 시간 | 성공 호출 | 자동 | 평균, 중앙값, n. 검색 + 생성 (+ 리라이트) 포함 |
| 오류 | 전체 시도 | 자동 | 오류 수, timeout 수 |

- Hit@5는 "필수 근거를 모두 찾았다"는 뜻이 아니다. 근거가 여러 개 필요한 문항의 누락은 보조 지표로 따로 본다.
- "최종 검색 결과"는 구성별 마지막 단계 출력이다: A = vector 상위 k, B = RRF 결합 결과, C = 재정렬 결과.

## 사람 채점 규칙

- 문항마다 채점자 2명이 각자 채점한다 (`*_r1`, `*_r2`). 다르면 둘이 합의해 최종값을 정하고 `note`에 이유를 쓴다.
- 채점자는 원본 기록(답변, 인용, 근거 청크 원문)을 보고 채점한다. 구성(A/B/C) 이름을 가리고 채점하는 것을 권장한다.
- 에이전트는 채점 칸을 채우지 않는다.

## 보조

| 지표 | 용도 |
| --- | --- |
| MRR@k, Recall@k | 순위 품질, 다중 근거 회수 |
| 재정렬 전후 순위 변화 | C의 효과 확인 |
| 리라이트 전후 Hit@5, 의도 변경 건수, fallback 건수, 추가 지연 | C+RW 검증 |
| 응답 시간 p95, 토큰 수 | 비용·지연 트레이드오프 |
| confusable 문항 오답 시 혼동 근거 선택 여부 | 유사 조건 구분 실패 분석 |
